# Civ6 区域配置シミュレーター (District Placement Simulator)

Civilization 6 (Gathering Storm) の**区域配置シミュレーター**です。React + Vite で作られており、GitHub Pages で静的配信できます。

- **自由配置モード**: 地形・地物・資源・川・区域を自由に編集し、隣接合計を確認
- **問題モード**: 6 つの定石テンプレートで最適配置を当てる学習用パズル
- **最適化探索**: 区域＋資源/改善を最大 6 項目まで総当たり（枝刈り＋Web Worker）で最適配置を提案

> 文明固有能力・指導者固有能力・政策カード・建造物による倍加は**未実装**（標準ルールのみ）。
> 最終的な正確性はゲーム内プレビューで確認してください。

## 起動

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド (dist/)
npm run preview  # ビルド結果の確認
npm run lint     # oxlint
```

## GitHub Pages デプロイ

`main`/`master` への push で `.github/workflows/deploy.yml` が自動ビルド・デプロイします。
リポジトリの Settings → Pages → Source で **GitHub Actions** を選んでください。
`vite.config.js` の `base: './'` により任意のリポジトリ名で動作します。

## 仕様

### 盤面

- ヘクスグリッド（axial 座標 `q, r`、半径 3、`|q + r| <= 3`）= **37 タイル**
- 複数都市対応: 都心は陸地にのみ配置、山岳・自然遺産・使用不可タイルには不可（高級・戦略資源・地熱孔の上は例外として可）。都心同士は 4 タイル以上離す。区域はいずれかの都心から 3 タイル以内。
- 1 タイル = 地形 + 地物(任意) + 資源/改善(任意) + 区域(任意)。他文明の領土などの配置できない範囲は、使用不可タイル（`blocked`）で表現できます。

各地形・川・都心/区域/資源への隣接といった固有設置条件を再現しています（建物レベル条件・首都条件・橋の直線条件は簡略化）。条件のない汎用遺産も選べます。

### 川

- 川はヘクスの**辺**の集合として表現します（`EDGES`）
- 頂点を共有する辺を連結成分としてまとめ、「同じ川」かどうかを判定します（`buildRivers`）
- 編集モードでは辺をクリックして追加・削除します

### 配置制限 (`checkDistrict`)

- 都心: 陸地にのみ配置できます。山岳・自然遺産・使用不可タイルには置けませんが、高級・戦略資源・地熱孔の上には置けます。他の都心とは 4 タイル以上離す必要があります
- 山岳 / 地熱孔 / 自然遺産 / 高級・戦略資源 / 使用不可タイルには区域・遺産を置けない
- **港 / ウォーターパーク**: 陸地に接する沿岸または湖タイルに置きます。礁の上には置けません
- **運河**: 水域に接する陸地に置き、都心に隣接するか、互いに隣接しない 2 つの水域に接している必要があります
- **軍事基地 / 保護区**: 都心に隣接できません。1 都市に 1 つまでの専門区域です
- **飛行場**: 平地にのみ置けます。1 都市に 1 つまでの専門区域です
- **宇宙基地 / 近郊住宅地**: 非専門区域で、人口スロットを消費しません。住宅地は 1 都市に複数置けます
- **外交街**: 1 文明に 1 つまで。専門区域で、区域の隣接（2 つごとに +1）のみ与え、政府複合施設のような +1 はありません
- 上記以外の区域は水域に置けません
- **用水路**: 都心に隣接し、都心側以外の辺で川・湖・オアシス・山岳のいずれかに接している必要があります
- **ダム**: 川が 2 辺以上に接する氾濫原に置きます。1 本の川に置けるダムは 1 つまでです
- 区域はいずれかの都心から 3 タイル以内
- 専門区域は人口スロット制です。上限は `1 + floor((pop-1)/3)` で、専門区域はキャンパス・聖地・商業ハブ・港・工業地帯・劇場広場・娯楽複合施設・ウォーターパーク・軍事基地・飛行場・保護区・政府複合施設・外交街、非専門区域は用水路・ダム・運河・宇宙基地・近郊住宅地です
- 専門区域・娯楽複合施設・ウォーターパーク・軍事基地・飛行場・保護区は 1 都市に 1 つ、政府複合施設・外交街は 1 文明に 1 つまでです。用水路・ダム・運河・宇宙基地・住宅地は複数置けます
- 区域を置くと、撤去可能な改善・地物（mine/quarry/sea/lumber_mill、woods/rainforest/marsh）は自動で撤去されます

### 隣接ボーナス (`scoreAt`, Civilopedia GS 準拠)

対象区域: キャンパス / 聖地 / 商業ハブ / 港 / 工業地帯 / 劇場広場

| 区域 | ボーナス |
|---|---|
| キャンパス | 山岳 +1、礁 +2、地熱孔 +2、熱帯雨林 (2 つごとに +1)、区域 (2 つごとに +1) |
| 聖地 | 山岳 +1、自然遺産 +2、森 (2 つごとに +1)、区域 (2 つごとに +1) |
| 商業ハブ | 川に接 +2（1 回）、港隣接 +2、区域 (2 つごとに +1) |
| 港 | 都心隣接 +2、海洋資源 +1、区域 (2 つごとに +1) |
| 工業地帯 | 用水路 +2、ダム +2、運河 +2、採石場 +1、戦略資源 +1、鉱山 (2 つごとに +1)、製材所 (2 つごとに +1)、区域 (2 つごとに +1) |
| 劇場広場 | 遺産 +2、娯楽複合施設 +2、ウォーターパーク +2、区域 (2 つごとに +1) |

共通の加算は次の 2 つです。
- 政府複合施設に接していると +1（下の区域隣接とは別に加算）
- 隣接区域（都心・用水路・ダムなど）は 2 つごとに +1。種別ごとに個別に切り捨てます

### 最適化 (`optimize`)

- 入力はベースマップと、配置する項目のリストです（区域と資源/改善を混在できます）
- 空きタイルに総当たりで配置し、`checkItem` で 1 件ずつ検証します
- 合計隣接ボーナス（SCORED 区域のみ）が最大になる配置を選びます
- UI では最大 6 項目まで選べます（Web Worker による非同期探索で、枝刈りと時間・ノード数の予算つき）

### 問題テンプレート (6 種)

| id | 名前 | 配置区域 |
|---|---|---|
| river-hub | 川沿い商業ハブ三角形 | commercial, campus, government |
| iz-dam | 工業地帯ダイヤ | industrial, aqueduct, dam |
| campus-pass | 山間キャンパス | campus, government |
| culture | 遺産と劇場広場 | theater, entertainment, government |
| harbor-hub | 港と商業ハブ | harbor, commercial |
| twin-cities | 双子都市 | campus, holy_site, theater, government |

各テンプレートが定めるのは地形・川・固定区域のみで、正解（最適配置）は `optimize` が計算します。

### 未反映・簡略化

- 盤面外周の辺の川。運河の水域接続の厳密な判定
- 遺産の建物レベル条件（図書館つきキャンパスなど）・首都条件・橋の直線条件、自然遺産の固有効果
- 文明・指導者固有能力、政策カード・建造物による倍加、都市国ボーナス、人口自動成長
- 「同じ川」は辺のつながりで判定しています（実ゲームでは川の名前で判定）

### 根拠

- 隣接値：Civilopedia（Gathering Storm）各区域ページ、Civ6 Planner 隣接表、civ6lib SKILL.md
- ダム・用水路・人口スロット・距離制限：Civilopedia／Civ Wiki／civ6lib
